Clone the repo and start your node:

Terminal
git clone https://github.com/machaao/llama-net.git
cd llama-net
pip install -r requirements-inference.txt
./start-app.sh --tunnel --bootstrap-peers https://llamanet.app

Or pre-load a model at startup:

Terminal (with model)
./start-app.sh run hf.co/user/Model:Q4_K_M \
  --tunnel \
  --bootstrap-peers https://llamanet.app
